# Claude Code governance configuration (generated)

Generated by `aisdlc governance plugin emit`. Two ways to enforce the tier policy:

1. **AGT Claude Code plugin** — point the plugin at a role policy:

   ```bash
   export AGT_CLAUDE_POLICY_PATH=$PWD/policy.implementer.json
   claude --plugin-dir /path/to/agent-governance-claude-code
   ```

   `hooks.json` mirrors the plugin's own hook wiring.

2. **Platform hook** — merge `settings.hooks.<role>.json` into `.claude/settings.json`;
   every PreToolUse call is classified into a risk tier, evaluated by the AGT policy
   engine and audited; PostToolUse results are screened for prompt injection.
