---
id: IFC-001
name: tickets command line
kind: cli
description: The `tickets` program (python -m tickets) over a JSON store file; this change
  adds `create/update --priority` and `list --sort priority`.
provider: tickets
consumers:
- support staff
- support automation scripts
contract: 'tickets [--store FILE] create TITLE [--priority P] | list [--status S] [--sort created|priority]
  | get ID | update ID [--title T] [--status S] [--priority P] | delete ID; records are JSON objects
  with id, title, status, priority, created_at; exit 0 ok, 1 not found, 2 invalid input'
version: '1.1'
