---
id: ADR-0001
title: Tool allow-list and approval set live in code, not in the prompt
status: proposed
context: Prompt-level restrictions can be argued away by injected text.
decision: SupportAssistant enforces allowed_tools/approval_tools before any call;
  the prompt only describes them.
consequences:
- Adding a tool is a code change reviewed under the ai_agent profile
alternatives:
- 'Prompt-only policy (rejected: bypassable)'
deciders:
- assistant-lead
- security
---
