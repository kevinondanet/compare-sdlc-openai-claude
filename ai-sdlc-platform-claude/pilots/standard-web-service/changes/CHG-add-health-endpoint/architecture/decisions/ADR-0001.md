---
id: ADR-0001
title: Run dependency checks in a bounded thread pool
status: proposed
context: A hung dependency must not hang the probe; checks are synchronous callables.
decision: Execute checks in a ThreadPoolExecutor with a 2 s result timeout; a timeout
  counts as a failed check.
consequences:
- Probe latency is bounded by the slowest check up to 2 s
alternatives:
- Async checks (would require an async server)
deciders:
- service-lead
---
